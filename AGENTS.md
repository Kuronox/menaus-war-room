# Menaus War Room

## Source of Truth

The HRF file is the only authoritative source for club data.

Never infer player information.

Never invent players.

Never assume attributes.

If data is missing, explicitly report it.

---

## Project Philosophy

War Room is a decision support system.

It is NOT a statistics dashboard.

Every feature must help answer:

"What should the manager do this week?"

---

## User Language

All responses to the user must be written in Spanish.

Source code must remain in English.

---
